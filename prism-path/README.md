# Prism Path

A mirror puzzle with 60 original levels, from Easy through Expert. Turn the mirrors and guide the light beam to the crystal.

## Play

Open `index.html` in a browser. The page has no build step or game-engine dependency.

## How it works

- Complete levels in order to unlock the next one.
- Tap or click a mirror to turn it; the beam updates immediately.
- Use Hint, Undo, and Restart as needed.
- Completed levels and the current level are saved in the browser.
- `levels.json` is the editable puzzle catalog. `levels.js` embeds the same catalog so the game also works when opened directly from disk.
