# GameBox Arcade

An original browser arcade hosted on GitHub Pages. Every game card opens a game on this site; there are no outbound game redirects.

- index.html, home.css, and home.js: animated, searchable, category-filtered shelf for 15 original games
- star-patrol/: 50-wave space war campaign with escalating enemy patterns and boss battles
- prism-path/: 60-level mirror puzzle
- cricket-cup/: timing-based six-ball cricket challenge with a detailed animated field
- snake-run/: classic keyboard and touch snake game with shaded animated garden visuals
- bubble-burst/: 60 progressive boards, with endless play after level 60
- block-workshop/: 60 progressively harder shape-placement levels plus endless play
- tower-builder/: precision tower-building arcade game
- chicken-crossing/: original lane-dodging road hopper
- skyline-runner/: original three-lane endless runner
- fruit-swipe/: original fruit slicing arcade game
- tic-tac-toe/: player versus a blocking/winning bot
- territory-trail/: original trail and territory game
- ludo-league/: original dice-and-token board game
- happy-glass/: original draw-to-guide-water puzzle
- privacy.html: disclosures for local game progress and Google services
- ads.txt: existing AdSense seller declaration

## Playgama partner catalog

`playgama-games.json` contains the selected partner catalog export. `playgama.js` creates searchable game cards, and `playgama-play.html` embeds each selected game on a page on this site. The partner game page does not load AdSense. The games are served by Playgama and its game partners, not hosted by this repository.
