# Srijan’s Arcade

An original browser arcade hosted on GitHub Pages. Every game card opens a game on this site; there are no outbound game redirects.

- index.html, home.css, and home.js: animated, searchable, category-filtered game shelf
- star-patrol/: 50-wave space war campaign with escalating enemy patterns and boss battles
- prism-path/: 60-level mirror puzzle
- cricket-cup/: timing-based six-ball cricket challenge
- snake-run/: classic keyboard and touch snake game
- bubble-burst/: aim-and-match bubble shooter with falling clusters and a rising ceiling
- block-workshop/: shape-placement block puzzle with line clears
- tower-builder/: precision tower-building arcade game
- privacy.html: disclosures for local game progress and Google services
- ads.txt: existing AdSense seller declaration
