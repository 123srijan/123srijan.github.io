# Srijan’s Arcade

A browser game catalog hosted on GitHub Pages. It features original games made for this site and links to selected games on their own websites.

- `index.html`, `home.css`, and `home.js`: searchable, category-filtered game catalog
- `star-patrol/`: original space battle game
- `prism-path/`: 60-level mirror puzzle
- `privacy.html`: privacy disclosures for local game progress, Google services, and third-party game links
- `ads.txt`: existing AdSense seller declaration
